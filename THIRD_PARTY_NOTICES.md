# Componentes de terceros

Las dependencias y sus versiones se fijan en `package-lock.json`. Sus avisos y licencias se conservan en los paquetes distribuidos. Esta lista identifica las dependencias principales; no sustituye sus textos de licencia.

| Componente | Licencia | Fuente |
|---|---|---|
| Next.js | MIT | https://github.com/vercel/next.js |
| React | MIT | https://github.com/facebook/react |
| React Aria Components | Apache-2.0 | https://github.com/adobe/react-spectrum |
| BlockNote Core, React y Ariakit | MPL-2.0 | https://github.com/TypeCellOS/BlockNote |
| Ariakit | MIT | https://github.com/ariakit/ariakit |
| Inter | SIL Open Font License 1.1 | https://github.com/rsms/inter |
| Lucide | ISC | https://github.com/lucide-icons/lucide |
| Playwright | Apache-2.0 | https://github.com/microsoft/playwright |
| Vitest | MIT | https://github.com/vitest-dev/vitest |
| axe-core | MPL-2.0 | https://github.com/dequelabs/axe-core |

El editor utiliza los paquetes base de BlockNote sin modificar su código fuente. No se incluyen paquetes XL. Los assets de la marca Aulify se mantienen separados de las bibliotecas de terceros.
