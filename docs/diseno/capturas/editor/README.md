# Capturas del editor

Capturas reales de Chromium, entorno de desarrollo local, 28 de septiembre de 2026. Datos de demostración creados en las pruebas automatizadas. No son capturas de producción ni resultados de una evaluación con estudiantes.

- `bloques-escritorio-oscuro.png`: bloques, tabla, cita, casilla, desplegable y código después de guardar y recargar; escritorio 1440 × 900 CSS px.
- `bloques-movil-oscuro.png`: el mismo recorrido en Pixel 7 (393 × 851 CSS px; raster con escala del dispositivo).
- `preguntas-escritorio.png`: preguntas de completar escribiendo y ordenar creadas durante el recorrido.
- `preguntas-movil.png`: controles de pregunta distribuidos en la composición móvil.

Origen: adjuntos de la ejecución aprobada de `tests/e2e/editor-bloques.spec.ts` (8/8). Las capturas conservan focos de teclado cuando estaban presentes. La automatización desactiva captura/bloqueo nativos del puntero; no verifica arrastre.
