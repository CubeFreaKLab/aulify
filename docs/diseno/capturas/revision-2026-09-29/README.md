Capturas reales de la demostración local, con datos ficticios, el 29 de septiembre de 2026.

- `editor-*`: documento completo a 1440×1000 y 390×844, claro y oscuro.
- `bloques-*`: menú de inserción del editor, incluida una comprobación adicional a 320 px.
- `landing-*`: portada con ilustración ajustada, incluido móvil de 320 px.
